## Descripción

El proyecto implementa un sistema de eventos universitarios utilizando Programación Orientada a Objetos en Java.

Se trabajaron los siguientes temas:

- Manejo de excepciones.
- Persistencia de objetos mediante serialización.
- Interfaces.
- Métodos genéricos y wildcards.
- Clases anidadas.
- Hilos de ejecución.

El sistema permite crear eventos, actividades y estudiantes, realizar inscripciones, emitir certificados, generar tickets de acceso y guardar y recuperar eventos desde archivos.
